# Changelog

## [1.0.6] – 2026-11-09
- "Start workout" is always on the home screen – on rest days and after you've already trained today.

## [1.0.5] – 2026-11-07
- New exercise order: back warm-up first, then standing exercises, then floor and ball, ending with the hamstring stretch – fewer changes of position and equipment.
- Each exercise shows its number on the physio's sheet.

## [1.0.4] – 2026-11-07
- Timed sets (holds, balance, stretch, plank) start automatically after a short "get ready".
- Pause / Resume on every timer, including rests.
- Voice countdown: "Hold… 3, 2, 1… Relax… 3, 2, 1" on every rep, "Last one" before the final rep.
- Longer timers and rests count down "3, 2, 1" out loud, and say "10 seconds" near the end.

## [1.0.3] – 2026-11-07
- The reps box is filled in with what you did last time for the same exercise, set and side.
- Fix: the right-side reps box started at 0 instead of the target.

## [1.0.2] – 2026-11-07
- "How to do it" is always collapsed when a new exercise starts; tap it to open.

## [1.0.1] – 2026-11-07
- Type your reps instead of tapping: the box is pre-filled with the target, so usually just tap "Set done".
- Rest between sets is now 30 seconds for every exercise.
- New 30-second rest after each exercise, showing the next exercise while you rest (change it in Settings).

## [1.0.0] – 2026-11-07
- First version: all 16 exercises from the physio plan, in English.
- Tap-to-count reps, countdown timers, hold/relax timer, rest timer between sets.
- Left/right side handling, beeps, vibration, voice cues, screen stays on during workouts.
- Training day / rest day (walk) tracking, history and back-pain rating after each workout.
- Edit sets, reps and timers per exercise. Backup export/import.
- Built-in updater: the app installs new versions from GitHub Releases.
