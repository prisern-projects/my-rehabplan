# Changelog

## [1.0.2] – 2026-11-07
- "How to do it" is always collapsed when a new exercise starts; tap it to open.

## [1.0.1] – 2026-11-07
- Type your reps instead of tapping: the box is pre-filled with the target, so usually just tap "Set done".
- Rest between sets is now 30 seconds for every exercise.
- New 30-second rest after each exercise, showing the next exercise while you rest (change it in Settings).

## [1.0.0] – 2026-11-07
- First version: all 16 exercises from the physio plan, in English.
- Tap-to-count reps, countdown timers, hold/relax timer, rest timer between sets.
- Left/right side handling, beeps, vibration, voice cues, screen stays on during workouts.
- Training day / rest day (walk) tracking, history and back-pain rating after each workout.
- Edit sets, reps and timers per exercise. Backup export/import.
- Built-in updater: the app installs new versions from GitHub Releases.
